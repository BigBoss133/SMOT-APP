🧪 [testing improvement] Add tests for ThemeContext

🎯 **What:** The testing gap addressed
The `ThemeContext` was missing tests, particularly the local storage fallback logic when accessing or modifying `localStorage` throws an exception (which can happen with restricted privacy settings or quota issues). The catch block was completely untested. We also needed tests for the context usage and toggling logic.

📊 **Coverage:** What scenarios are now tested
- The default fallback theme ('dark') is provided when `localStorage` is empty.
- The stored theme is successfully loaded from `localStorage` when available.
- The theme correctly toggles between 'light' and 'dark', and updates `localStorage`.
- The fallback logic works properly when `localStorage.getItem` or `localStorage.setItem` throws an error.
- An error is correctly thrown when `useTheme` is consumed outside of `ThemeProvider`.

✨ **Result:** The improvement in test coverage
Test coverage for `ThemeContext.tsx` is now at 100% (Statements, Branches, Functions, and Lines).

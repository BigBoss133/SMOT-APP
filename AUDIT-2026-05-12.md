## Miglioramenti consigliati

- Aggiungere test E2E (Playwright già configurato) e script `npm run test:e2e`
- Eseguire `cargo test` in `src-tauri` e integrare `tauri-driver` per test integrati
- Configurare GitHub Actions per `npm run lint`, `npm run build`, `cargo fmt --check`
